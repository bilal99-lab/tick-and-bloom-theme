# Tick & Bloom theme

WordPress theme for [tickandbloom.com](https://tickandbloom.com), free printable habit trackers and planners.

- Imported from the live site (Hostinger) on 19 Nov 2026, version 1.0.8 (`TICK_BLOOM_VERSION` in `functions.php`).
- Live path on the server: `public_html/wp-content/themes/tick-bloom/`
- Fonts are loaded from the site root `/assets/fonts/`; a copy is kept in `root-assets/fonts/` (deploy to `public_html/assets/fonts/`, not into the theme).
- Rule while the redesign is in progress: theme changes are made here, not on the server.
